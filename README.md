# 桃下拳闘

桃陰、もものすけ、自作ファイターで戦う、桃下村塾のブラウザ格闘ゲームです。

## 遊び方

PCのブラウザで開き、練習、CPU対戦、ローカル対戦のいずれかを選びます。ローカル対戦では、1台のPCとキーボードでふたりが遊べます。

| 操作 | 1P | 2P |
| --- | --- | --- |
| 移動 | A / D | ← / → |
| 弱 / 強パンチ | F / G | J / K |
| ガード / 回避 | S / W | ↓ / ↑ |
| 必殺技 | H | L |

Escで一時停止。カスタムファイターと録音ボイスはブラウザ内に保存されます。

## ローカルで起動

リポジトリのファイルをダウンロードし、同じフォルダ構成のまま index.html をChromeで開きます。
