# 桃下拳闘 v2

[ブラウザで遊ぶ](https://tyantou2.github.io/momositakakutou/)

桃陰、もものすけ、自作ファイターで戦う桃下村塾のブラウザ格闘ゲームです。PCでURLを開くか、ファイルを同じフォルダ構成のまま展開して `index.html` をChromeで開きます。

## 遊び方

- **CPU対戦**は「はじめて」と「通常」。**ローカル対戦**は同じPCのキーボードで2人対戦。**練習**は時間制限がなく、必殺技を何度でも試せます。
- 対戦は3分1ラウンド。時間切れでは残った体力の割合で判定します。
- 弱パンチは発生が早く、強パンチは長く届きます。ガードを崩されたり、スタミナ不足の状態でスタミナを使う行動を出そうとしたりすると、約1.5秒スタンします。
- 後ろ回避は下がって距離を取り、その場回避は位置を保ったまま避けます。ジャンプ中も弱・強パンチを出せます。
- 必殺技はゲージ100%で約1.1秒のカットインを挟んで発動し、1試合につき最大2回。1回目以降はゲージの溜まる速度が落ちます。

| 操作 | 1P | 2P |
| --- | --- | --- |
| 左右 | ← / → | A / D |
| ジャンプ・ガード | ↑ / ↓ | W / S |
| 弱・強パンチ | J / K | F / G |
| 後ろ回避・その場回避 | I / O | Q / E |
| 必殺技 | L | H |

`Esc` で一時停止・再開できます。外見・身長・能力・必殺技・ボイスをカスタマイズしたファイターはブラウザ内に保存されます。身長は10段階。v1のキャラは保存済みの外見に近い段階へ変換します。

## 音声と素材

- 桃陰のゲーム用ボイス　**VOICEVOX:青山龍星**（熱血）
- もものすけのゲーム用ボイス　**VOICEVOX:猫使ビィ**
- 音声は本作のために合成したゲーム用の掛け声です。転用時はクレジットを記載し、各音声の規約に従ってください。[VirVox Project](https://virvoxproject.wixsite.com/official/voicevoxの利用規約)・[猫使プロジェクト](https://nekotukarb.wixsite.com/nekonohako/利用規約)
- 道場は生成イラスト。戦闘用立ち絵は桃下村塾のマスコット原画を参考に制作した試作素材です。
