## v3.4 村長「二面変身」

両者が同じ最新版へ更新してオンライン対戦してください。共有シードと保存可能な乱数状態を用い、ロールバックしても抽選・壁・飛び道具が再現されます。

## 遊び方

- **CPU対戦**は「はじめて」と「通常」。**ローカル対戦**は同じPCのキーボードで2人対戦。**練習**は時間制限がなく、必殺技を何度でも試せます。
- 対戦は2分1ラウンド。時間切れでは残った体力の割合で判定します。
- 弱パンチは発生が早く、強パンチは長く届きます。ガードを維持すると毎秒4ずつスタミナを消費します。ガードを崩されたり、スタミナ不足の状態でスタミナを使う行動を出そうとしたりすると、約1.5秒スタンします。
- 後ろ回避は下がって距離を取り、その場回避は位置を保ったまま避けます。ジャンプ中も弱・強パンチを出せます。着地には約0.2秒の後隙があります。
- 通常攻撃では攻撃が届く直前の3フレームに回避を入力するとジャスト回避。相手の攻撃が中断され、約0.67秒間反撃できます。成功後2秒間は通常回避です。
- 必殺技はゲージ100%で発動します。標準のカットインは約1.1秒、桃陰ともものすけは技名表示と専用動画を挟み、1試合につき最大2回。1回目以降はゲージの溜まる速度が落ちます。連続必殺技は初撃が命中すると最後までつながります。

| 操作 | 1P | 2P |
| --- | --- | --- |
| 左右 | ← / → | J / L |
| ジャンプ・ガード | ↑ / ↓ | I / K |
| 弱・強パンチ | S / D | N / M |
| 後ろ回避・その場回避 | Q / W | U / O |
| 必殺技 | E | P |
| 変身中の専用技1 / 2 | A / F | Y / H |

`Esc` で一時停止・再開できます。外見・身長・能力・必殺技・ボイスをカスタマイズしたファイターはブラウザ内に保存されます。身長は10段階。v1のキャラは保存済みの外見に近い段階へ変換します。

## 桃陰の白桃砕き

桃陰が白桃砕きを発動すると、まず技名を約0.8秒表示してから、新しいGemini動画の0.300〜3.750秒（約3.45秒）を再生します。冒頭の静止した構えを飛ばし、エネルギーが動き始めた場面から表示します。技名表示中に再生位置を準備し、未準備の先頭フレームは表示しません。顔のアップと背後へのカメラ移動を見せ、動画内のパンチが始まる前に短い桃色の発光を挟んで実際の対戦画面へ戻ります。1P・2Pの向きに合わせて映像を反転します。動画中は試合時計と行動が停止し、パンチと敵の被弾は現在の対戦データから描画します。

動画素材は1280×720・16:9を維持した約1.4MBのMP4です。ゲーム側は映像全体を比率を保って表示します。提供元の約10秒の動画はゲームに含めず、元ファイルも保持しています。動画の音声は使用せず、発動時の溜め音、動画終盤から打撃へ重ねる聖騎士紅桜の技名ボイス、命中時の重低音を使います。

復帰後は約0.17秒で打撃が出ます。動画を溜めの一部として扱い、技の発生準備を進めてから復帰し、元の総踏み込み距離を残り10フレームの動きに反映します。ダメージ・ゲージ消費・射程・ガードや回避の判定・ヒットストップ・物理的な吹き飛びの値は既存の仕様です。命中時のみ短いインパクトフレーム、大きな桃色と白の衝撃波、のけぞりと吹き飛びの描画を表示します。

読み込み・再生に失敗した場合は既存のカットインを使います。設定でカットインの動きをオフにした場合も既存の静止演出です。

## 必殺技に対する防御

技名表示と動画の間は、双方のキャラクター、試合時計、スタミナ、防御の経過時間を停止します。必殺技の発動が成立したフレームで、相手のガード・回避状態を記録します。発動前から成立していたガード、または無敵時間内の回避を最初の一撃で判定し、演出の長さで無効にはしません。最初の一撃までは新しい操作入力を受け付けず、演出を見てから押したガード・回避・ジャンプや移動の入力を持ち越しません。CPUにも同じ制限が適用されます。

必殺技に対するジャスト回避は、必殺技発動時点までの直近3フレームに実際に入力した回避に限ります。古い入力や成功後2秒の再発動制限中は通常回避です。回避の無敵がすでに終了していた場合は回避できません。射程外・空中との高さ・ガードの成立条件・スタミナ不足によるガード崩しは従来どおりです。待機して相手の攻撃を返すカウンター技は、演出後に相手の操作を止めません。

## v3.0「ゃん」とオンライン対戦

初期キャラクターに「ゃん」を追加しました。提供された本人のキャラクター画像を基に、透明背景のゲーム用立ち絵とパンチのポーズを新規生成しています。身長6、移動6、威力5、追加能力は持久4・回避3・防御3。眼鏡、黒髪、紺の服、白い靴を維持しています。

専用必殺技「蒼閃・一文字」は21Fの溜めから踏み込む三連撃（基礎威力13×3）。初撃が命中すれば最後までつながり、最終打で大きく吹き飛ばします。蒼い残像、眼鏡の閃光、交差する衝撃線、最終打の青白いインパクトフレーム、ヒットストップと打撃音を組み合わせています。空振り後の隙は36F。キャラ作成の選択肢には含めず、不正な保存データで専用技を指定しても通常の技へ戻します。

### 招待コードで遊ぶ

1. 両者が同じ公開URLをPCのChromeまたはEdgeで開き、「オンライン対戦」を選びます。
2. 一人が「部屋を作る」で表示した8文字のコードを相手に共有します。
3. もう一人がコードを入力して「参加する」を押します。
4. 接続後、それぞれ自分のファイターを選び、双方が「準備完了」で開始します。

ゲスト側も矢印キーとQ・W・E／S・Dを使います。画面のYOU表示が自分です。初期キャラと保存済みの自作キャラを使えます。自作キャラの外見と能力は共有しますが、アップロードしたボイスは相手に送信しません。

オンライン対戦に一時停止はありません。対戦中は画面を開いたままにしてください。「退出」で終了します。通信待ちを表示し、長く進行できない場合や切断時には結果を勝手に確定せず終了します。再戦する場合は対戦準備へ戻り、新しく部屋を作ってください。

### 通信

PeerJS 1.5.5（MIT、ライブラリとライセンスをvendorに同梱）の共有接続サービスで相手を見つけ、WebRTCで接続します。標準のSTUN／TURN設定を使用します。根拠：[PeerJS公式](https://peerjs.com/server/cloud)、[1.5.5の接続設定](https://github.com/peers/peerjs/blob/v1.5.5/lib/util.ts)。

60Hzの入力を送信し、開始時の往復時間から3〜5F（約50〜83ms）の入力遅延を選択、最大8Fまで予測し、到着した入力と異なれば状態を巻き戻して再計算します。確定済みの効果音・ヒット演出は一度だけ出します。定期的に確定状態を比較し、同期がずれた場合は案内して終了します。動画の読み込み速度や演出オフ設定が双方で違っても、オンライン中の必殺技は同じ戦闘時間で進みます。

通信遅延が完全になくなることは保証できません。回線と共有接続サービスの状態に影響されます。別の家庭回線・携帯回線同士を使った実機検証は未実施です。
