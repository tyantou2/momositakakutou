# 桃下拳闘 v2.3

[ブラウザで遊ぶ](https://tyantou2.github.io/momositakakutou/)

桃陰、もものすけ、自作ファイターで戦う桃下村塾のブラウザ格闘ゲームです。PCでURLを開くか、ファイルを同じフォルダ構成のまま展開して `index.html` をChromeで開きます。

## 遊び方

- **CPU対戦**は「はじめて」と「通常」。**ローカル対戦**は同じPCのキーボードで2人対戦。**練習**は時間制限がなく、必殺技を何度でも試せます。
- 対戦は2分1ラウンド。時間切れでは残った体力の割合で判定します。
- 弱パンチは発生が早く、強パンチは長く届きます。ガードを維持すると毎秒6ずつスタミナを消費します。ガードを崩されたり、スタミナ不足の状態でスタミナを使う行動を出そうとしたりすると、約1.5秒スタンします。
- 後ろ回避は下がって距離を取り、その場回避は位置を保ったまま避けます。ジャンプ中も弱・強パンチを出せます。着地には約0.2秒の後隙があります。
- 攻撃が届く直前の3フレームに回避を入力するとジャスト回避。相手の攻撃が中断され、約0.67秒間反撃できます。成功後2秒間は通常回避です。
- 必殺技はゲージ100%で約1.1秒のカットインを挟んで発動し、1試合につき最大2回。1回目以降はゲージの溜まる速度が落ちます。連続必殺技は初撃が命中すると最後までつながります。

| 操作 | 1P | 2P |
| --- | --- | --- |
| 左右 | ← / → | J / L |
| ジャンプ・ガード | ↑ / ↓ | I / K |
| 弱・強パンチ | S / D | N / M |
| 後ろ回避・その場回避 | Q / W | U / O |
| 必殺技 | E | P |

`Esc` で一時停止・再開できます。外見・身長・能力・必殺技・ボイスをカスタマイズしたファイターはブラウザ内に保存されます。身長は10段階。v1のキャラは保存済みの外見に近い段階へ変換します。
